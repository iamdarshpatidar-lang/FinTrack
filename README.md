
# FinTrack

A Personal Finance Management Application built using Java and Spring Boot.

## About

FinTrack helps users manage their personal finances by tracking income, expenses, budgets and savings goals.

## Technology Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Thymeleaf
- MySQL
- Maven
